AI tool

OpenAI Codex desktop coding agent, operating on the local repository through the Codex app.

Model

The specific underlying model/version was not exposed in the working environment. This is stated rather than guessed.

What it produced

The static site architecture, HTML/CSS/JavaScript, data-cleaning script, derived JSON, report drafts, and codebook drafts.

What it did not do

It did not verify the original source, manually check 50 entries, or claim that human_checked values were positive.

What the AI was asked to do

AI 被要求做什麼

  • Read the project brief and implement its requirements.
  • Inspect and clean the supplied 500-row CSV into a web-ready JSON dataset.
  • Build search, filters, linked visualizations, a data grid, and CSV export.
  • Draft the learning report, codebook, and this declaration in English and Traditional Chinese.
  • Check the site locally and prepare it for GitHub Pages.
  • 閱讀專題簡章並實作要求。
  • 檢查並清理所提供 500 列 CSV，轉為網站可用的 JSON。
  • 建立搜尋、篩選、連結式視覺化、資料表格與 CSV 匯出。
  • 以英文及繁體中文起草學習報告、分類準則與本聲明。
  • 在本機檢查網站，並準備發佈至 GitHub Pages。

What the project owner must do themselves

專題擁有者必須自行完成的事

Required before submission: identify the source corpus/version and sampling method; verify a random sample of at least 50 entries against the original; correct errors; update human_checked for those entries; review and rewrite the codebook definitions in your own words; and confirm copyright and privacy suitability.

提交前必須完成：確認來源語料庫版本與抽樣方法；對照原始來源隨機核對至少 50 條；修正錯誤；更新那些條目的 human_checked；以自己的文字審閱並改寫分類準則定義；確認版權與私隱適合公開展示。

Example prompts

提示詞例子

Read the attached project brief and implement it for me. Do not fabricate source metadata or mark records as human-checked. Preserve the raw CSV and make the cleaning method reproducible.

This prompt framed the non-negotiable boundaries: the agent should build rather than invent, and it should expose missing evidence.

請閱讀附件簡章並替我實作。不要虛構來源資訊，也不要把紀錄標為人工已核對。保留原始 CSV，並使清理方法可重現。

這個提示詞界定了不可妥協的界線：AI 應建置而非虛構，並揭露缺失的證據。

One thing AI got wrong

AI 曾做錯的一件事

The first category implementation used a hand-written semantic list to decide which renderings were “literal.” That was not reproducible from the data and would have made the codebook depend on the agent's opaque judgment. I noticed it when checking the resulting category counts against the raw term pairs. The rule was replaced with a frequency-based consistency classification, and the change is recorded in the codebook log.

第一版分類使用手寫語義清單來判定哪些譯法屬於「直譯」。這種做法無法從資料重現，會使分類準則依賴 AI 不透明的判斷。我在核對分類計數與原始詞項配對時發現了問題。規則後來改為基於頻率的一致性分類，變更已記錄在分類準則的修訂紀錄中。

Limits of the AI contribution

AI 貢獻的界限

AI is useful for making structures, generating interface code, and surfacing inconsistencies. It is not evidence of source authenticity, translation quality, or human verification. The assistant did not browse the original corpus and cannot tell whether the supplied sentence IDs correspond to the dataset named in the brief. Those gaps remain the most important part of the project's reflection.

AI 有助於建立結構、生成介面程式碼與揭露不一致；但它不是來源真實性、翻譯品質或人工核實的證據。助理沒有瀏覽原始語料庫，也無法判斷所提供句子 ID 是否對應簡章所指的資料集。這些缺口仍是本專題反思中最重要的部分。
